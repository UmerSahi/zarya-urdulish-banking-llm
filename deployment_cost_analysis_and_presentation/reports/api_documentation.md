# Production API Documentation & OpenAPI Specification

**Client:** Zarya Digital Bank (Pakistan)  
**Task:** Week 10 Capstone — Day 5 Task 5  
**Base URL:** `http://localhost:8000` (or `https://api.zaryabank.com`)  
**Specification:** OpenAPI 3.0 / Swagger Compatible  

---

## 1. Authentication & Security Headers

In production, all endpoints require an enterprise bearer token or mutual TLS (mTLS) handshake between the Mobile App Gateway and the AI Inference Service:
```http
Authorization: Bearer <ZARYA_INTERNAL_GATEWAY_JWT>
Content-Type: application/json
```

## 2. API Endpoints

### 1. Health & Cluster Status
* **Endpoint:** `GET /health`
* **Description:** Health probe for Kubernetes, AWS ECS, or Docker Compose.
* **Response (200 OK):**
```json
{
  "status": "healthy",
  "service": "Zarya AI Banking Serving Gateway",
  "model_engine": "Qwen 2.5 3B (LoRA + DPO Aligned)",

```

### 3. OpenAI-Compatible Chat Completions
* **Endpoint:** `POST /v1/chat/completions`
* **Description:** Fully compatible with OpenAI Python SDK, LangChain, or ChatBot UI. Supports streaming via Server-Sent Events (`stream: true`).
* **Request Body:**
```json
{
  "model": "zarya-qwen-2.5-3b-urdulish-dpo",
  "messages": [
    {"role": "user", "content": "PayPak debit card ki annual fee kitni hai?"}
  ],
  "temperature": 0.2,
  "stream": false
}
```

### 5. Continuous Feedback Ingestion
* **Endpoint:** `POST /api/feedback`
* **Description:** Ingests user ratings (+1 or -1) to populate the DPO fine-tuning loop.
* **Request Body:**
```json
{
  "session_id": "sess_mobile_app_98210",
  "user_query": "Manager ne OTP maanga tha",
  "assistant_response": "OTP kisi ko na batayein",
  "rating": -1,
  "feedback_category": "tone_too_short",
  "comment": "Did not display full official warning."
}
```
* **Response (200 OK):**
```json
{
  "status": "success",
  "feedback_id": "FB-8A2F1C99",
  "flagged_for_dpo": true
}
```
