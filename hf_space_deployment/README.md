# Zarya Digital Bank — UrduLish Banking LLM Assistant
**Week 10 Capstone Project — Production Deployment**

An enterprise-grade, domain-specialized AI assistant fine-tuned on Pakistani banking conversations in **UrduLish** (Roman Urdu + English banking terms) with automated dispute ticket generation and State Bank of Pakistan (SBP) cybersecurity guardrails.

### Features
* **UrduLish Customer Assistant:** Authentic conversational support across Raast, IBFT, ATM failures, cards, and accounts.
* **Support Agent CRM:** Automated ticket creation with SLA Turnaround Time (TAT) and human escalations.
* **Regulatory Guardrails:** 100% block rate on OTP/PIN phishing attacks.
* **Hybrid RAG:** Dynamic tariff verification without retraining.
